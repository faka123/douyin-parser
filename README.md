# 多平台视频解析下载

## 本地运行

需要 Node.js 20 或更新版本。

```sh
npm ci
npm run browser:install
npm run build
npm start
```

打开 http://localhost:3000 。支持粘贴完整分享文案。
本机已安装 Google Chrome 时会优先使用它；否则使用 Playwright Chromium。
Linux 部署可用 `npx playwright install --with-deps chromium` 安装浏览器及系统依赖。
部署需要安装运行依赖中的 `playwright`、提供足够内存启动浏览器，并允许访问抖音及视频 CDN。
`PORT` 环境变量可更改服务端口。

## 抖音解析

先检查分享页数据；缺失时启动独立、临时的无头浏览器，监听抖音页面自身发送的视频详情请求。
浏览器会在成功或超时后关闭，不使用本机 Chrome 的用户资料或登录状态。
最多同时进行两次浏览器解析。验证码、登录限制或平台变动仍可能导致解析失败，页面会提示重试。

下载地址直接取自视频详情的 `play_addr.url_list` / `bit_rate`，清晰度按视频实际尺寸显示。
不再拼接旧播放接口或把 1080p 标成 4K。返回的媒体链接有时效，过期后需要重新解析。
当前抖音流程支持视频，图集及实况图集未实现。其他平台仍使用原有解析器，尚未全面验证。
SnapAny 通用解析代码目前没有接入运行流程。

## 下载与地址恢复

解析响应的 `data.downloads` 提供默认、带水印和各清晰度的下载链接。
下载接口只接受服务器签发的随机 `token`，不再接受任意 `url`。
凭证有效期 30 分钟，服务器重启后失效，重新解析即可获取新凭证。
最多保存 2000 个凭证，较早凭证可能被淘汰。

下载前依次尝试同一视频流的备用 CDN 地址；全部失败时重新解析原分享链接一次。
所选清晰度消失时提示重新解析，不静默降低画质。已经开始传输的下载中断时需重新下载。
请求连接与重定向目标均限制为公开网络地址，拒绝本机、内网和非 HTTP/HTTPS 协议。
服务器请求不使用环境代理，避免代理绕过 DNS 地址校验。

开发模式使用 Node 自带的文件监听：`npm run dev`。

## 本机代理兼容

默认拒绝所有非公网地址。若本机使用代理的 Fake-IP DNS 模式，正常平台域名可能被解析到 `198.18.0.0/15`。
可在不提交的 `.env` 文件中配置 `ALLOW_FAKE_IP=1`。
该选项仅允许代码中列出的平台及 CDN 域名使用这一地址段，仍拒绝 IP 直连、本机和其他内网地址。
云端通常无需开启；不要将本机 `.env` 提交到仓库。
